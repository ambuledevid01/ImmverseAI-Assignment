# Notebooks Directory

This directory contains Jupyter notebooks used for:
1. **Exploratory Data Analysis (EDA)**: Inspecting historical manuscript page dimensions, aspect ratios, faded ink levels, and layout variation.
2. **Annotation Inspection**: Visualizing ground-truth region labels (`header`, `footer`, `main_text`, `side_text`, `filler`).
3. **Experimentation**: Prototyping image preprocessing techniques and model evaluation.

### Recommended Notebooks Structure
- `01_eda_manuscript_analysis.ipynb`: Data exploration and distribution of layout region bounding boxes.
- `02_preprocessing_experiments.ipynb`: Testing skew correction, contrast enhancement, and binarization.
